/**
 ***************************************************************************************************
 * 实验名称：LCD 系统状态监控 (System Monitor)
 * 实验平台：MZXQ F407 开发板
 * 实验目的：通过 LCD 实时显示 STM32F407 的 CPU 使用率、时钟频率、Flash/RAM/ExtSRAM
 *           内存占用及运行时间，学习 FSMC 接口 LCD 驱动及系统资源监控方法。
 ***************************************************************************************************
 * 硬件资源分配
 * 1 LED
 *     DS0(RED)   : LED0 - PF9  (系统运行指示灯)
 * 2 按键
 *     KEY0    - PE4   (当前空闲，保留扩展)
 *     KEY_UP  - PA0   (当前空闲，保留扩展)
 * 3 串口1 (PA9/PA10，通过板载 DAPLINK 连接电脑)
 *     波特率：115200
 * 4 MZXQ 2.8/3.5/4.3/7/10 寸 TFTLCD 模块 (FSMC 接口，16 位 8080 总线)
 * 5 外部 SRAM 芯片 IS62WV51216BLL (1MB，FSMC 接口，地址 0x68000000)
 ***************************************************************************************************
 * 实验功能
 * 1 LCD 实时显示系统状态信息（每 300ms 刷新，约 5fps）：
 *    ┌─────────────────────────────┐
 *    │       System Monitor        │  顶部标题栏
 *    ├─────────────────────────────┤
 *    │  CPU / Clock                │  卡片1：CPU & 时钟
 *    │  CPU:    [=====     ]  xx% │    - CPU 使用率（进度条+百分比）
 *    │  SYSCLK: 168 MHz  PCLK2:...│    - SYSCLK/HCLK/PCLK1/PCLK2
 *    │  HCLK:   168 MHz            │
 *    │  PCLK1:   42 MHz            │
 *    ├─────────────────────────────┤
 *    │  Memory                     │  卡片2：内存占用
 *    │  Flash:   [==        ] xx% │    - 内部 Flash (1MB)
 *    │  IntRAM:  [====      ] xx% │    - 内部 RAM  (128KB)
 *    │  ExtSRAM: [          ] xx% │    - 外部 SRAM (1MB)
 *    ├─────────────────────────────┤
 *    │  Status                     │  卡片3：运行状态
 *    │  Uptime: HH:MM:SS           │    - 运行时间
 *    └─────────────────────────────┘
 *
 * 2 资源监控指标说明：
 *   - CPU 使用率  ：DWT 硬件周期计数器测量，统计 work_start~work_end 区间占比
 *   - Flash 占用  ：链接器符号 ER_IROM1 Length（代码+常量+初始化数据）
 *   - RAM 占用    ：RW_IRAM1 Length（.data+.bss） + 当前栈使用量
 *   - ExtSRAM 占用：通过扫描 0x68000000~0x680FFFFF 非 0x00/0xFF 字节估算
 *   - 进度条颜色  ：绿色(<70%) / 黄色(70~90%) / 红色(>90%)
 *
 * 3 LED0 闪烁指示程序运行状态（约 1Hz）
 ***************************************************************************************************
 * 新增模块说明
 * ─────────────────────────────────────────────────────────────────────────────
 * 路径                                     功能
 * ─────────────────────────────────────────────────────────────────────────────
 * Drivers/BSP/SYS_INFO/sys_info.h/c      系统信息采集（CPU/时钟/内存）
 * Drivers/BSP/LCD_STATUS/lcd_status.h/c  LCD GUI 状态界面（深色主题）
 * ─────────────────────────────────────────────────────────────────────────────
 *
 * CPU 测量原理：
 *   - 使用 Cortex-M4 内置 DWT CYCCNT 周期计数器（每 CPU 周期 +1）
 *   - sys_info_work_start() 记录起始周期
 *   - sys_info_work_end()   累加工作周期
 *   - 每 1s 计算：CPU% = 工作周期 / 理论总周期 × 100
 *
 * GUI 配色（RGB565 深色主题）：
 *   - 背景色    : 0x0843  深灰蓝
 *   - 卡片背景  : 0x10A2  深灰
 *   - 标题栏    : 0x2B5F  深蓝
 *   - 标签文字  : 0x9CD3  浅灰
 *   - 数值文字  : 0xFFFF  纯白
 *   - 时钟数值  : 0x7FFF  青色
 ***************************************************************************************************
 * 注意事项
 * 1 串口助手波特率设置为 115200
 * 2 使用 XCOM/SSCOM 等串口工具时，关闭 DTR/RTS 功能以避免 MCU 复位
 * 3 选择 LCD 型号时需确认驱动 IC 型号（支持 ILI9341/ST7789/NT35310 等）
 * 4 P10 排针 PA9/PA10 连接串口，对应丝印 RXD/TXD
 * 5 4.3 寸及以上大屏功耗较大，建议使用外部电源供电
 ***********************************************************************************************************
 * 平台：MZXQ F407
 ***********************************************************************************************************
 */
