======== 1. 控制模式总览 ========

local_mode 定义 (mode_manager):
  0 = ZERO_TORQUE     零力矩透明 (默认安全态)
  1 = GAIT            自适应步态 (下肢位置轨迹 + 上肢阻抗摆臂)
  2 = ARM_ASSIST      鳌臂助力 (上肢 ABO 重力悬停)
  3 = INDUSTRIAL      工业助力 (全关节 ABO 工业模式)

关节索引:
  0=左髋, 1=右髋 (CAN1/CyberGear)
  2=左肩, 3=左肘, 4=右肩, 5=右肘 (CAN2/RS01)

各模式上下肢控制方式对照:
┌──────────────┬─────────────────────┬─────────────────────┬─────────────────────┐
│ 模式         │ 下肢 (idx 0,1)      │ 上肢 (idx 2~5)      │ ABO 状态            │
├──────────────┼─────────────────────┼─────────────────────┼─────────────────────┤
│ ZERO(0)      │ TORQUE 0 透明       │ TORQUE 0 + 软限位   │ 全关 enable=0       │
│              │ (回归期:POSITION回归)│ (限位内仍透明)      │ assist_torque清零   │
├──────────────┼─────────────────────┼─────────────────────┼─────────────────────┤
│ GAIT(1)未运行│ TORQUE 0 透明       │ TORQUE 0 透明       │ 腿 enable=1 gain=0  │
│              │                     │                     │ 臂 enable=1 gain=0  │
├──────────────┼─────────────────────┼─────────────────────┼─────────────────────┤
│ GAIT(1)运行  │ POSITION 步态表     │ TORQUE 阻抗摆臂     │ 腿 enable=1 gain=默认│
│              │ Kp=3 Kd=1.0         │ (低刚度+死区)        │ 臂 gain=0(阻抗接管) │
├──────────────┼─────────────────────┼─────────────────────┼─────────────────────┤
│ ARM_ASSIST(2)│ TORQUE 0 + ABO      │ TORQUE 0 + ABO      │ 腿 gain=arm_level映射│
│              │ (透明跟随)          │ (重力悬停)          │ 臂 gain=256(0.25×)  │
├──────────────┼─────────────────────┼─────────────────────┼─────────────────────┤
│ INDUSTRIAL(3)│ TORQUE 0 + ABO工业  │ TORQUE 0 + ABO工业  │ 全关节 industrial=1 │

└──────────────┴─────────────────────┴─────────────────────┴─────────────────────┘


======== 2. ABO 观测器 ========

运行时机: 1ms ISR, 在命令生成之后、CAN 发送之前, 就地修改 syn_target。
源码: control_isr.c abo_update_one()

---------- 2.1 医疗模式 (idx 0~5, industrial_mode=0) ----------

流程:
  1. tau_meas = js->torque (mNm, 相电流推算)
  2. 偏置估计: bias_est += leak·(tau_meas - bias_est)   [吸收重力+常值摩擦]
  3. HPF 提取人力: hpf_state += α·(tau_meas - bias_est - hpf_state)
     tau_human = hpf_state
  4. 助力: tau_assist = (gain · tau_human) >> 10
  5. 限幅 ±3000 mNm, 叠加到 cmd->syn_target

参数 (按关节/相位分离):
┌─────────────────┬──────────────┬──────────────┬──────────────┐
│ 关节/相位       │ gain (Q10)   │ α (Q16)      │ leak (Q16)   │
├─────────────────┼──────────────┼──────────────┼──────────────┤
│ 默认 (所有)     │ 1024 (1.0×)  │ 655 (~1.6Hz) │ 66 (~1s)     │
│ 腿-站立相        │ 1024         │ 4000         │ 66           │
│ 腿-摆动相        │ 1024         │ 1000         │ 200          │
│ 臂 (GAIT模式)   │ 0 (阻抗接管) │ 1000         │ 20           │
│ 臂 (ARM_ASSIST) │ 256 (0.25×)  │ 1500 (~3Hz)  │ 25 (~4s)     │
└─────────────────┴──────────────┴──────────────┴──────────────┘
注: 站立/摆动相由 g_gait_phase 判定 (idx0: phi<=0.5站立, idx1: phi>0.5站立)

---------- 2.2 工业模式 (industrial_mode=1) ----------

★ 核心变更: 人力检测改用「速度推断」, 不再用 tau_meas 带通。
  原因: 纯力矩模式下 tau_meas≈命令, 不反映静态人力;
        用 tau_meas 做带通会把命令变化误当人力 → 正反馈狂转;
        扣除自身 assist 又引入延迟振荡。改用速度推断根治。

流程:
  1. tau_meas = js->torque (仅用于偏置估计/负载突变检测)
  2. 偏置估计: 极慢积分 (leak=10/65536 ≈ 60s), 负载突变冻结 500ms
     冻结条件: |Δτ| > 2000 mNm
  3. ★ 速度推断人力:
     vel_rad = js->velocity / RAD_TO_MDEG  (mdeg/s → rad/s)
     死区: |vel| < 0.15 rad/s (8.6°/s) → tau_human = 0
     上限: |vel| > 3.0 rad/s (172°/s) → tau_human = 0 (防过速)
     tau_human = K_VEL · vel_eff  (同向助力, 负阻尼性质)
  4. 增益调度 (按 load_est_q10, tasks.c 异步更新):
     load < 5 N·m  → gain=1024 (1.0×)
     load < 15 N·m → gain=512  (0.5×)
     load ≥ 15 N·m → gain=256  (0.25×)
  5. 输出 LPF (防振荡): α=5000/65536 (~12Hz), 复用 hpf_state 字段
  6. 限幅 ±1500 mNm, 叠加到 cmd->syn_target

工业模式参数:
  K_VEL        = 0.6   Nm·s/rad  (负阻尼系数, 须 < 系统摩擦)
  VEL_DEADZONE = 0.15  rad/s
  VEL_MAX      = 3.0   rad/s
  输出LPF α    = 5000/65536 (~12Hz)
  偏置 leak    = 10/65536 (~60s)
  冻结时长     = 500 ms
  冻结阈值     = 2000 mNm
  限幅         = ±1500 mNm (±1.5 N·m)

  ⚠ 调参提示: K_VEL 是负阻尼, 过大会降低系统阻尼致振荡/加速失控。
    现场若振荡, 优先调小 K_VEL; 助力太弱则调大 (仍须 < 摩擦)。


======== 3. GAIT 步态算法 ========

---------- 3.1 下肢步态轨迹 (POSITION 模式) ----------

步态表 (5 点插值, 单位 mdeg):
  点位    左髋      右髋
  0%        0      30000
  25%    15000     15000
  50%    30000         0
  75%    15000     15000
  100%      0      30000
  摆幅: 0~30° (原 60° 已降, 正常行走髋屈伸约 ±25°)
  周期: 4000 ms
  插值: 线性 + 梯形速度平滑 (max_vel=60000 mdeg/s)
  启动渐变: 2 秒 (ramp_scale 0→1024)
  POSITION 参数: Kp=3.0, Kd=1.0 (can_motor.c 发送时)
    (原 Kp=10 Kd=0.5, 降刚度防僵硬对抗, 增阻尼防振荡)
  位置限位: [-30000, 90000] mdeg (LOCAL_HIP_POS_MIN/MAX)

---------- 3.2 上肢阻抗摆臂 (TORQUE 模式) ----------

★ 方向约定: 臂电机正方向 = 解剖反方向 (4 臂全部反相, 用户确认)
  ARM_DIR = -1.0
  阻抗在解剖系定义, 经坐标变换后仅 ref 项乘 ARM_DIR:
    τ = K·(ARM_DIR·ref - pos) + B·(0 - vel)   [Nm → mNm ×1000]

参考轨迹 (arm_phi 为相位):
  arm_phi = (arm_idx >= 2) ? phi : phi + 0.5   (左右臂反相)
  肩: ref = 0.5 · (-cos(2π·arm_phi))           ∈ [-0.5, 0.5] rad
  肘: ref = 0.5 + 0.3 · sin(2π·arm_phi)        ∈ [0.2, 0.8] rad

刚度/阻尼 (按相位连续调制, 避免跳变振荡):
  phase_gain = 0.5 - 0.5·cos(2π·phi)   [0→1→0, 站立相=1]
  肩: K = 0.1 + 0.4·pg    B = 0.1 + 0.5·pg
  肘: K = 0.05 + 0.25·pg  B = 0.03 + 0.15·pg
  (原 K 肩 0.3~1.5 → 0.1~0.5, 大幅降刚度减弱主动拉扯)

死区: |tau_imp| < 150 mNm → 不输出
  (零位未标定时 pos 有偏移, 死区避免持续小力对抗)
限幅: ±300 mNm (±0.3 N·m, 原 ±500 已降)
重力前馈: 关闭 (tau_ff=0, 需零位标定后用 MGL·cos(θ-θ₀) 重开启)


======== 4. 重力 / 摩擦补偿 (仅 ARM_ASSIST 模式) ----------

仅在 local_mode=2 且 STANDALONE 模式下, 对臂关节施加。
源码: control_isr.c torque_compensate()

系数表 (idx 0=左肩,1=左肘,2=右肩,3=右肘):
  g_gravity_mgl = {6963, 1638, 6963, 1638}  mNm  (肩7N·m, 肘1.6N·m)
  g_gravity_bv  = {  80,   40,   80,   40}  (粘性系数, ×vel>>10)
  g_gravity_cc  = { 300,  150,  300,  150}  mNm  (库仑摩擦, 带方向)

公式:
  ff = MGL·cos(θ) + BV·vel/1024 + CC·sign(vel)
  target += damping(vel) + friction(vel) + ff

注: ZERO 模式跳过所有补偿 (透明); GAIT 模式臂用阻抗, 不走此路径。


======== 5. 安全机制 ========

---------- 5.1 上肢 ±90° 软限位 ----------
源码: control_isr.c arm_soft_limit_torque()
  限位: ±90° (90000 mdeg, 相对机械零位)
  软带: 90°~105° (15° 带内线性增至满力矩)
  回复力矩上限: 1.5 N·m (1500 mNm)
  应用: 所有臂 TORQUE 路径 (含 ZERO 透明模式, 限位内 soft=0 保持透明)
  位置正超限 → 负向拉回; 位置负超限 → 正向拉回

---------- 5.2 碰撞检测 ----------
源码: control_isr.c 臂发送段
  阈值: SAFETY_COLLISION_TORQUE_DELTA = 8000 mNm (8 N·m/ms 突变)
  触发: 力矩突变 > 阈值 → 瞬间零力矩 + rs01_mit_disable + FAULT_COLLISION
  模式切换时重置 arm_tau_prev, 防止误触发
  ZERO 模式跳过 (透明模式不检测)

---------- 5.3 GAIT→ZERO 平滑回归 ----------
  检测: prev_mode==GAIT && transitioning
  回归: 3 秒, POSITION 模式 15°/s 向 0° 收敛
  期间 ABO 全关, 上肢 TORQUE 0
  回归完成 → 切纯 TORQUE 0

---------- 5.4 ZERO 模式安全切断 ----------
  ABO: enable=0 (停观测器), assist_gain=0, g_abo_assist_torque=0 (清前馈)
  力矩: 直接发 0, 跳过 rate_limit/compensate (防渐变期间持续受力)
  软限位: 仍生效 (限位内 soft=0, 透明)

---------- 5.5 力矩限幅汇总 ----------
┌──────────────────────┬───────────────┬────────────────────────┐
│ 位置                 │ 限幅 (mNm)    │ 说明                   │
├──────────────────────┼───────────────┼────────────────────────┤
│ GAIT 上肢阻抗        │ ±300          │ ±0.3 N·m, 柔软         │
│ ABO 医疗模式         │ ±3000         │ ±3.0 N·m               │
│ ABO 工业模式         │ ±1500         │ ±1.5 N·m (防失控)      │
│ 软限位回复           │ ±1500         │ ±1.5 N·m               │
│ PID torque_limit     │ pp->tlimit    │ 参数表配置             │
└──────────────────────┴───────────────┴────────────────────────┘


======== 6. 方向约定 ========

臂电机 (RS01 MIT 模式) 正方向 = 上肢解剖反方向
  (4 臂关节全部反相, 用户确认)
  ARM_DIR = -1.0

影响:
  - GAIT 上肢阻抗: ref 项乘 ARM_DIR (pos/vel 项因 S²=1 不变)
  - ABO 测量/命令同在电机系, S 自动抵消, 无需改动
  - 工业模式速度推断: vel 直接用电机系读数 (同向助力, 方向自洽)

腿电机方向: 未报告异常, 按原约定 (正方向=屈髋/前摆)


======== 7. 已知限制 / 待标定项 ========

1. 零位未标定
   - GAIT 上肢重力前馈关闭 (tau_ff=0)
   - pos_rad 有常值偏移, 靠阻抗死区 (150mNm) 缓解
   - 待: 硬件标定 θ₀ 后, 用 MGL·cos(θ-θ₀) 重开启重力前馈

2. 工业模式速度推断是负阻尼
   - K_VEL 须 < 系统摩擦系数才稳定
   - 当前 0.6 是保守值, 需现场调参
   - 不区分人力与命令引起的速度 (近似处理, 靠限幅+死区+LPF 保障安全)

3. GAIT 步态是开环轨迹
   - 不跟随用户意图, 用户不跟则被拉 (已降幅度30°+降刚度Kp=3 缓解)
   - 待: 后续可改为步态相位自适应 (检测用户迈步意图同步相位)

4. 纯 TORQUE 模式无法检测静态人力
   - tau_meas≈命令, 不含静态外部负载反作用
   - 工业模式已改速度推断 (动态检测); 医疗模式仍有此限制
   - 待: 若需静态人力检测, 需力传感器或 POSITION 模式 (Kp>0 让电机反抗)

5. ESO3/导纳路径 (v2.0) 默认关闭
   - eso_enable=0, 全 inactive
   - g_joint_state (§A/§B) 与 g_arm_status (ABO) 互不干扰
   - 待: ESO3 调参收敛后可启用替代 ABO
