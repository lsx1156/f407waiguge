## 1. 目的

为三件后续工作提供**真实人体运动数据**：

| 用途 | 需要的量 |
|---|---|
| ① 替换验证台的"手挑工况" | 真实关节角频谱/幅值包络 θ(f)、θ̇(f) |
| ② 相位调度助力 | 连续多周期的相位参考（无 IMU，相位只能从关节角提取） |
| ③ 在线辨识（m_load/θ0）设计与验证 | 已知负载下的 τ_meas-运动对照 |

## 2. 前提约束（用户已锁定）

| 约束 | 取值 | 影响 |
|---|---|---|
| 场景 | **台架**，PC 在场 | 走以太网 UDP 数据流 |
| 受试 | **实体穿戴**（真人穿戴） | 会话时长受疲劳限制、需安全规程 |
| 模式 | **仅 ZERO（零阻力）**，其余三模式**硬禁用** | 无助力扰动 → 运动为自然运动；无失控风险 |
| 关节 | 6 个：`L/R-Hip`（CAN1, CyberGear）、`L/R-Shldr`、`L/R-Elbow`（CAN2, RS01） | 无膝/踝；"步态"数据仅含髋 |
| 传感器 | ABS 编码器（θ/θ̇）+ 相电流 ADC | **无 IMU、无称重传感器** |

**模式锁定要求**：采集固件版本必须把 GAIT / ARM_ASSIST / INDUSTRIAL 三条路径**编译期或运行期硬禁**（`mode_manager` 拒绝切换 + 相关代码不参与链接），确保穿戴者不可能意外获得助力。

## 3. 采集原理（为什么 ZERO 模式的数据恰好是最优的）

零力矩指令下，六台电机均为**可反驱动**（准直驱）。人转动关节时，电机被反驱动：

```
τ_meas  ≈  τ_人施加在关节上的力矩  −  (装置自身重力 + 装置惯量项 + 装置摩擦)
```

**这是关键**：`τ_meas` 正是 ABO 算法的输入量，且**在 ZERO 模式下它就是人力的直接测值域**（不需要靠逆动力学反推）。因此本方案采到的数据集

```
(θ, θ̇, τ_meas, τ_cmd≡0)  ⟶  就是算法设计/标定所需要的那组量
```

**但要扣除装置自身项**，故需要：
1. **G0 静置基线**（人完全放松、装置自由下垂）→ 得到装置自身重力/惯量/摩擦的特征与 `τ_meas` 零偏；
2. **装置质性参数**（CAD/3D 模型 + FP64 离线 RNEA）→ 从 `τ_meas` 中扣除装置自身项，得到净人力量；
3. **G7 力矩测值校核**（已知质量、已知半径施加静力矩）→ 先确认 `τ_meas` 的可信度与线性度。

## 4. 采集量清单（每关节）

## 5. 数据通路（台架 + 以太网）

### 5.1 板侧改动

| # | 改动 | 位置 | 量级 |
|---|---|---|---|
| 1 | 新增**数据流帧类型 `0x02`**，批量搬运日志帧（**不动现有 112 B 控制协议**） | `udp_protocol.c/h` | ~80 行 |
| 2 | 暂存 FIFO：`JOINT_LOG_BUF_SIZE` 256 → **1024 帧（~30 KB）**；如不足则挂 `sram.c` 外部 SRAM | `joint_unit.h:220` | 改宏 + 少量代码 |
| 3 | 流控：上位机下发「开始/停止采集 + 会话 ID」，板侧回 ACK | `udp_protocol.c` | ~40 行 |
| 4 | **模式硬禁**：ZERO 专用采集固件 | `mode_manager.c` | ~20 行 |

### 5.2 PC 侧（上位机重写）

`上位机/upper_host.py` 可改且**未落地**，因此按采集需求重新设计为双职能：

| 职能 | 要点 |
|---|---|
| ① 实时控制/监视 | 保留现有 UDP 5001 控制链路、CRC16、心跳 |
| ② **无丢包落盘** | 独立接收线程（GUI 刷新绝不阻塞收包）；`SO_RCVBUF` 调大；**板上 `ts_ms` 为唯一时钟**，PC 仅记到达时刻用于监测漂移 |
| 实时仪表 | 带宽、**seq 缺口数**、限幅计数、各关节 θ̇ 噪声 RMS、温度 |

**丢包对策（必须写进设计）**：UDP 无重传。180 kB/s 虽仅占百兆网 1.4%，但 socket 缓冲/系统负载仍可能丢包 →
- 批量 **50 ms**、**序列号缺口检测**；
- 单次工况仅 20~60 s，**发现缺口即重采该组**，成本可忽略；
- 若要求绝对可靠，需在 LwIP 上开 TCP（固件工作量上一个台阶，本方案不采用）。

## 6. 采样参数

| 项 | 取值 | 理由 |
|---|---|---|
| 采样率 | **1 kHz**（可降档 500 Hz） | 与控制环同频；周期运动主频 0.5~2.5 Hz，过采样留足离线差分求角加速度的余量 |
| 批量 | 50 ms/包（6 关节 × 50 = 300 帧） | 20 包/s |
| 带宽 | **180 kB/s ≈ 1.44 Mbit/s** | 百兆网占用 1.4% |
| 存储 | 11 MB/min；15 min 会话 ≈ **165 MB** | 落 PC 盘 |

## 7. 工况矩阵

> 拍频用**节拍器**引导（无 IMU，无法自动判定频率/相位）；每组前留 5 s 静止、后留 5 s 静止，便于分段。
> 各关节软限位（`safety.h`）：肩 [+150°, −30°]、肘 [+140°, 0°]、髋 [+90°, −30°]。

| 编号 | 工况 | 涉及关节 | 参数 | 时长×次数 | 服务于 |
|---|---|---|---|---|---|
| **G0** | 静置基线 | 全部 | 人完全放松、装置自由下垂、不动 | 30 s ×3 | `τ_meas` 零偏、噪声底、装置自身重力特征 |
| **G1** | 单关节主动摆动 | 逐个 6 关节 | f = 0.5 / 1.0 / 1.5 / 2.0 / 2.5 Hz × 摆幅 小/中/大 | 20 s ×18 | **真实工况包络** θ(f)、θ̇(f) |
| **G2** | 髋部步态样 | L/R-Hip | 原地踏步 / 慢走（**取决于台架是否允许**） | 60 s ×5 | 步态相位、髋部协调 |
| **G3** | 上肢往复作业 | 肩+肘 | 抓取-搬运-放置往复 | 60 s ×5 | 工业工况相位调度 |
| **G4** | 已知附加质量 | 肩+肘 | 手持 **+2 / +5 kg**（记录质量与握点位置）做 G1/G3 | 20 s ×12 | **在线辨识 ground truth** |
| **G5** | 被动扫掠 | 逐个 6 关节 | 人放松，由检查者缓慢驱动 0.05→3 rad/s 正反 | 10 s ×6 | 分离库仑/粘性摩擦（校核 `k_fric` 上限） |
| **G6** | 软限位边界 | 逐个 6 关节 | 缓慢逼近各关节软限位 | 10 s ×6 | 限位行为、姿态覆盖 |
| **G7** | 力矩测值校核 | 肩+肘（水平位） | 挂已知质量于已知半径，静态保持 | 10 s ×6 | **`τ_meas` 可信度/线性度**（决定后续一切） |

**G7 与 G4 是方案的核心价值**：没有称重传感器时，"载荷不确定度到底吃掉多少精度"只能靠已知负载的基准数据来标定。

## 9. 文件格式

```
session_YYYYMMDD_HHMM_<工况>.bin     定长记录，小端
session_YYYYMMDD_HHMM_<工况>.json    同名头（§8 元数据 + 通道定义 + 记录长度）
```

记录布局（每帧，packed）：

| 偏移 | 字段 | 类型 |
|---|---|---|
| 0 | `ts_us` | uint32 |
| 4 | `seq` | uint32 |
| 8 | `joint_idx` / `phase` / `mode` | uint8 ×3 |
| 11 | `pos_rad` | float32 |
| 15 | `vel_rad_s` | float32 |
| 19 | `tau_meas` | float32 |
| 23 | `tau_cmd` | float32 |
| 27 | `tau_human` | float32 |
| 31 | `adm_scale` | float32 |
| 35 | `temp_c` | float32 |
| — | 合计 | **39 B/帧** |

180 kB/s → 以 39 B/帧计约 **234 kB/s**（仍仅占百兆网 1.9%）。

## 10. 质控指标（不达标即重采）

| 指标 | 阈值 |
|---|---|
| 采样抖动（`ts_us` 间隔标准差） | < 1% |
| 丢包率（seq 缺口） | < 0.1% |
| 帧数完整性 | = 速率 × 时长 ± 0.1% |
| 限幅计数 | 0（ZERO 模式不应触发） |
| 静止段 θ̇ 噪声 RMS | 记录基线值，供后续滤波设计 |
| `tau_cmd` 恒零校验 | 全段 \|τ_cmd\| = 0 |

## 11. 安全规程（真人穿戴）

1. 受试者穿戴后**先空载低速试动**，确认装置零阻力、无异响、软限位生效；
2. **模式锁定**：仅 ZERO 可进入，其余模式硬禁用（§2）；
3. 急停可达（物理急停 + 上位机 ESTOP 心跳）；
4. 单组 ≤60 s，组间休息 ≥30 s，总时长 ≤45 min/次，防疲劳；
5. 活动范围预热（ROM warm-up）后再采；
6. **G4 附加质量不超过软限位允许的承载**，且由操作者保护；
7. G2 走动若台架不允许则**取消该组**，不冒险。

## 12. 后处理流水线

```
录 (θ, θ̇, τ_meas, τ_cmd≡0, 温度, 负载质量)
  ├─ ① 分段/去基线/滤波（保留相位不失真：零相位滤波）
  ├─ ② 扣装置自身项: τ_human ≈ τ_meas − RNEA(装置, θ, θ̇, θ̈)   ← 3D 模型 + FP64 离线
  ├─ ③ FFT → 真实频谱与幅值包络 θ(f)、τ(f)  → 替换验证台工况
  ├─ ④ 相位提取（过零/希尔伯特）→ 相位调度助力表
  ├─ ⑤ G4 已知负载回归 → 在线辨识器 (m_load/θ0) 设计与验证
  └─ ⑥ G5 扫掠 → 库仑/粘性摩擦分离 → 校核 k_fric ≤ 0.7
```

## 14. 未决项 / 风险

| # | 项 | 说明 |
|---|---|---|
| R1 | **`τ_meas` 零力矩下的可信度未知** | 零指令下电流很小，估计器零偏/温度补偿误差可能主导 → **G7 必须先做**，不通过则整条路要改（改用逆动力学反推人力） |

| R4 | 台架是否允许踏步/走动（G2） | 不允许则取消该组 |
| R5 | 受试者数量与个体差异 | 建议 ≥3 名受试者，否则包络只对单人有效 |
